# Mobile packaging
This is the Capacitor preparation layer for Android/iOS.
1. Deploy and verify the web application.
2. Configure production Supabase and payment services.
3. Add native platforms with Capacitor.
4. Add final icons/splash assets.
5. Test authentication, quizzes, competitions and payments on real devices.
6. Build signed Android `.aab` and iOS archive.
Never embed Supabase service-role or payment secret keys in the mobile client.
